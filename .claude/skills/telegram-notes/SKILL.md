# Telegram → заметки

Работай из корня проекта, где лежат `.env` и `notes/`. Все команды ниже запускай оттуда.

## 1. ВЗЯТЬ

```bash
python3 .claude/skills/telegram-notes/scripts/tg_notes.py fetch
```

Скрипт берёт токен из `TELEGRAM_BOT_TOKEN` или из `.env`, вызывает `getUpdates` с offset из `notes/.telegram_offset`, пропускает не-текстовые сообщения и печатает JSON:

```json
{"next_offset": 123, "skipped_non_text": 1,
 "messages": [{"update_id": 122, "text": "...", "date": "2026-11-03", "author": "@user"}]}
```

- Если скрипт упал с ошибкой, сообщи её пользователю и остановись. Токен никогда не выводи.
- Если `messages` пустой, скажи «Новых сообщений нет» и заверши работу. Если при этом `skipped_non_text > 0`, всё равно запусти `save` с пустым массивом `[]`, чтобы сдвинуть offset.

## 2. ОБРАБОТАТЬ

Каждое сообщение классифицируй сам:

- **task (задача)**: конкретное действие, обычно глагол-команда, часто со сроком или результатом. Пример: «Позвонить бухгалтеру завтра».
- **idea (идея)**: мысль, «а что если», конкретного шага нет. Пример: «Можно сделать бота для рецептов».
- **Если сомневаешься, выбирай idea.**

Если в задаче есть срок («завтра», «до пятницы», «15 ноября», «в 18:00»), вынеси его в `deadline` дословно, как он написан в сообщении. Если срока нет, укажи `null`. Текст сообщения ты не передаёшь и не переписываешь: скрипт берёт оригинал по `update_id`.

## 3. ПОЛОЖИТЬ

Передай классификацию **всех** сообщений из `fetch` в stdin:

```bash
python3 .claude/skills/telegram-notes/scripts/tg_notes.py save <<'EOF'
[
  {"update_id": 122, "kind": "task", "deadline": "завтра"},
  {"update_id": 123, "kind": "idea", "deadline": null}
]
EOF
```

Скрипт:
- дописывает задачи в `notes/tasks.md` в формате `- [ ] текст — срок: ... (дата, @автор)`; если срока нет, часть `— срок:` опускается;
- дописывает идеи в `notes/ideas.md` в формате `- текст (дата, @автор)`;
- создаёт файл с заголовком, если его нет, и никогда не перезаписывает существующий;
- сдвигает `notes/.telegram_offset` только после успешной записи обоих файлов.

Если `save` упал, offset не сдвинут и сообщения придут снова при следующем запуске. Сообщи об ошибке пользователю.

Не редактируй `notes/tasks.md` и `notes/ideas.md` вручную через Edit/Write. Всё пишет только скрипт.

## Отчёт

В конце коротко отчитайся:

```
Получено сообщений: N (пропущено не-текстовых: K)
Задач: X, идей: Y

✅ Позвонить бухгалтеру завтра (срок: завтра)
💡 Можно сделать бота для рецептов
```

Каждое сообщение одной строкой: ✅ для задачи, 💡 для идеи. Длинные тексты обрезай примерно до 80 символов с «…».
