# telegram-notes

Скилл для Claude Code, который превращает сообщения из Telegram-бота в заметки. Он забирает новые текстовые сообщения, определяет, задача это или идея, и дописывает их в `notes/tasks.md` и `notes/ideas.md`.

Запуск: команда `/telegram-notes` в Claude Code.

## Алгоритм

Полное описание лежит в [`.claude/skills/telegram-notes/SKILL.md`](.claude/skills/telegram-notes/SKILL.md). Кратко:

1. **Взять.** Скрипт `tg_notes.py fetch` вызывает `getUpdates` Telegram Bot API с offset из `notes/.telegram_offset`. Он пропускает не-текстовые сообщения, сохраняет текстовые в `notes/.telegram_pending.json` и печатает их в виде JSON.
2. **Обработать.** Claude относит каждое сообщение к одному из двух видов:
   - **задача**: конкретное действие, часто со сроком («Позвонить бухгалтеру завтра»);
   - **идея**: мысль без конкретного шага («Можно сделать бота для рецептов»).

   Если вид неясен, сообщение считается идеей. Срок («завтра», «до пятницы», «в 18:00») выносится отдельно, дословно, как в сообщении.
3. **Положить.** Скрипт `tg_notes.py save` получает классификацию в stdin и берёт исходный текст сообщения по `update_id`, так что Claude текст не переписывает. Скрипт дописывает в файлы:
   - `notes/tasks.md`: `- [ ] текст — срок: ... (дата, @автор)`;
   - `notes/ideas.md`: `- текст (дата, @автор)`.

   Существующие файлы не перезаписываются. Offset сдвигается только после успешной записи обоих файлов, поэтому при сбое сообщения не теряются и придут снова.
4. **Отчёт.** Claude выводит, сколько сообщений получено, и показывает каждое одной строкой: ✅ для задачи, 💡 для идеи.

## Структура

| Путь | Назначение |
|---|---|
| `.claude/skills/telegram-notes/SKILL.md` | Инструкции скилла: алгоритм и правила классификации |
| `.claude/skills/telegram-notes/scripts/tg_notes.py` | Скрипт: `fetch` (забрать сообщения) и `save` (записать заметки) |
| `.claude/commands/telegram-notes.md` | Команда `/telegram-notes`, вызывает скилл |
| `notes/tasks.md`, `notes/ideas.md` | Заметки |

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Положите токен в `.env` в корне проекта:
   ```
   TELEGRAM_BOT_TOKEN=123456:ABC...
   ```
   Файл `.env` указан в `.gitignore` и в репозиторий не попадает.
3. Напишите боту сообщения и вызовите `/telegram-notes` в Claude Code.
